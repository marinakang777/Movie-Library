Описание
Приложение «Movie Library» — это простая личная кинотека с графическим интерфейсом. Позволяет добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга. Данные сохраняются в формате JSON. Доступна фильтрация по жанру и году.
Технологии

- Python 3.x.
- Tkinter (GUI).
- JSON (сохранение/загрузка данных).
- Git (контроль версий).

## Использование

1. Запустите main.py.
2. Введите данные о фильме и нажмите «Добавить фильм».
3. Используйте фильтры для поиска по жанру или году.
4. Данные сохраняются автоматически.
Приложение использует публичный GitHub  (https://github.com).
Для запуска прложения склонируйте репозиторий:

запустите программу Movie Library

Примеры использования приложения Movie Library:

Добавьте фильм: «Начало», жанр: «Фантастика», год: 2010, рейтинг: 8.8.
Добавьте фильм: «Ирония судьбы», жанр: «Комедия», год: 1975, рейтинг: 8.2.
Проверьте фильтрацию по жанру «Фантастика» и по году 1975.
Закройте и откройте приложение — данные должны сохраниться.
